# Code of Conduct

## Our standard

We are committed to a respectful, technically rigorous, and harassment-free community. Be direct about evidence and tradeoffs while remaining constructive toward the people involved.

Examples of expected behavior include:

- Giving actionable feedback focused on code and product behavior.
- Respecting privacy and never publishing another person's prompts, transcripts, credentials, or account data.
- Welcoming contributors with different experience levels and backgrounds.
- Correcting mistakes transparently.

Harassment, discrimination, personal attacks, doxxing, sexualized conduct, and deliberate disclosure of private information are not acceptable.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile. Security vulnerabilities must use the process in [SECURITY.md](SECURITY.md). Maintainers may edit, reject, or remove contributions and participation that violate this standard.

This policy applies in repository issues, pull requests, discussions, and other project spaces.
